Token de sesión del panel

Para leer el clip en D1 la extensión necesita tu token de sesión del panel (el mismo que el panel guarda en su localStorage como “avc-session”). Lo pegas una vez aquí; vive solo en este Chrome, como la API key. Sin él, el chequeo de D1 no se puede hacer y los envíos se bloquean, así no se duplica nada. Cómo sacarlo: panel AVC abierto y con sesión → F12 → Application → Local Storage → avc-em9.pages.dev → copia el valor de “avc-session”. No es una contraseña de ninguna red.
