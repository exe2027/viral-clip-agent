## 4. No borrar el clip hasta terminar todas las plataformas (17 nov, §9)

- El archivo del clip NO se borra cuando se publica en una plataforma.
  Se borra solo cuando TODAS las plataformas aprobadas están en estado
  terminal: publicado, fallido, expirado (TTL 72 h) o cancelado.
- El panel muestra el estado por plataforma en cada clip.
- Borrado manual: siempre disponible, pero con aviso que liste las
  plataformas pendientes. Sin ese aviso, no se borra.
- Si una plataforma falla: su entrada queda para reintento o para resolverla
  a mano; no bloquea a las demás ni borra el clip.
- La pieza ya existe en el agente (`publish_queue.json` / `PublishQueue`
  llevan una entrada por plataforma con estado propio); lo que se arregla
  es el borrado del panel.
